# Message Service - Микросервис для управления сообщениями
## 🎯 Обзор
**Message Service** — это Spring Boot микросервис для управления сообщениями с поддержкой транзакционного outbox паттерна и интеграцией с Kafka. Сервис предоставляет REST API для создания сообщений, сохраняет их в PostgreSQL и гарантированно отправляет события в Kafka.

Основная цель: Надежное хранение сообщений с гарантированной доставкой событий в Kafka, используя паттерн Transactional Outbox.

## ✨ Ключевые особенности
|Особенность	| Описание |
|------|----------------------------------------------------|
|🗄️ PostgreSQL	|Надежное хранение сообщений|
|🚀 Kafka Integration	|Асинхронная отправка событий|
|🔄 Transactional Outbox	|Гарантированная доставка сообщений|
|📊 PriorityBlockingQueue	|Очередь с приоритетом для обработки|
|🛡️ Fault Tolerance	|Retry механизм и обработка ошибок|
|📈 Real-time Monitoring	|Статистика и health checks|

## Паттерн Transactional Outbox
```text
1. Получение HTTP запроса
2. Начало транзакции
3. Сохранение сообщения в messages
4. Сохранение события в outbox_messages (в той же транзакции)
5. Коммит транзакции
6. Фоновый процесс отправляет событие из outbox в Kafka
7. При успешной отправке - пометка события как обработанного
```
